Caixa de ferramentas do motion

Um motion é feito de camadas. Cada vídeo escolhe uma opção (ou algumas) de cada camada. O vídeo fica chato quando todas as camadas repetem: mesma tipografia entrando, mesmo som, mesma transição, só texto.

Legenda de status - ✅ No motor: já funciona no motions. - 🟢 Pronto para portar: já é código Remotion (shotcraft, remocn, projeto do Grok); adaptar é rápido. - 🟡 Receita + código: está em HTML/canvas (lemo); precisa traduzir para o Remotion. - ⚪ Só ideia: existe só como descrição.

Fontes: lemo = lemo-opuscar (100 estilos) · shotcraft = video-shotcraft (124 cartões de tomada) · remocn = biblioteca remocn (~200 componentes) · grok = founderpapers-kit.

Contagens atuais (geradas):

  • Marcas: 1 (founderpapers) + modelo conteudo/marcas/_modelo/.
  • Estilos no catálogo (conteudo/estilos/catalogo.json): 105 — 103 sob-demanda, 1 pronto, 1 em-teste. Implementados no motor: colagem (pronto), scifi-toon (em-teste). 99 vêm do lemo-opuscar; 0 com licença pendente.
  • Ferramentas no catálogo (ferramentas/catalogo.json): 457 — 194 gerais + 263 próprias de estilo; status: 457 portada. Registradas no código: 457.
